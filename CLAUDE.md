# syntrak-suit-app

Python Qt app: connect to the suit, record, sync the SD card, live plots. Part of Syntrak: the home repo is the parent folder (`../CLAUDE.md`), with the context map and glossary.

## Git

Follow `docs/git-protocol.md` in syntrak-home, the parent folder (`../docs/git-protocol.md`, or https://github.com/Syntraksoftware/syntrak-home): `type(scope): what changed`, `type/short-desc` branches, squash-merged PRs whose title is checked in CI. Scope for this repo: `suit-app`. Never push or merge without the owner's yes.
